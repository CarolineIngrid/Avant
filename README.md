# Projeto de Dashboard Analítico - React

Este é um projeto frontend feito com **React**, inspirado em uma interface moderna de visualização de dados. Aqui você pode fazer login com um usuário simples para acessar um painel com gráfico.

## 🚀 Tecnologias Utilizadas

- React
- Tailwind CSS
- Vite (ou Create React App)
- Recharts (para gráficos)
- Mock de dados local

## 🔧 Como rodar o projeto

1. **Clone o repositório:**


git clone https://github.com/CarolineIngrid/Avant.git
cd client
